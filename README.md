# Sistema de Control de Rescate y Adopción Animal

## Descripción
Proyecto académico para el diseño de un sistema de gestión de rescate y adopción animal.

## Objetivo
Organizar el registro de animales rescatados, los casos de rescate, la atención veterinaria y las solicitudes de adopción.

## Actores principales
- Ciudadano o reportante
- Voluntario
- Veterinario
- Administrador del refugio
- Adoptante

## Diseño del sistema
El proyecto contempla diagramas UML, patrones de diseño y principios SOLID.

## Control de versiones
Se utilizará Git y GitHub para organizar los cambios mediante ramas de trabajo.
